# 实验设计与实际结果

所有数字来自固定种子构造数据的实际运行，未使用真实账单。

## 数据与划分

共3000条记录，训练/验证/测试数量为{'train': 1825, 'validation': 603, 'test': 572}。商户组和关联事件不跨集合；不同集合使用不同句式模板族，类目关键词共享。TF-IDF只在训练集拟合。

模型按验证集Macro-F1选择为 **NB**，不按测试集最高分挑选。分类阈值为0.4，也是在验证集选择。

## 纠正反馈、体检与OCR

个性化适应使用18条自习空间消费纠正，12个不同商户留出测试，准确率从0%变为100%。留出样例共享同一种服务描述，这是单一偏好适应探针，不代表普遍泛化。
人工反馈比例使用真值模拟计算，不是招募真实用户得到的实测结果。
体检独立探针30条记录中人为删除5个商户，检测5个；关闭体检的主测试结果不变，因为主测试字段完整。

## 已发现问题与修复证据

- 初版撤销后重新确认不能结束任务：补充终止检查点重新进入finish的处理，回归测试覆盖完整路径。
- 初版OCR按文本块换行，列被拆开：按检测框纵向位置合并，再做字段提取；压缩图片中的日期与时间无空格也已覆盖。
- 初版在采样负例上选择匹配阈值，实际候选分布的精确率较低：改用验证集全部候选选阈值，保留训练时的负例采样；不使用测试集选阈值。
- 模糊商户“扫码支付”仍缺少可靠类别依据，保留人工核对；异常检测存在误报，用户确认后才纳入汇总。
