# 真实 API 接入与验证

本次使用用户选择的兼容接口和 `qwen3.7-flash`。密钥仅保存在本机.env，没有写入仓库、报告或请求日志。平台显示的输入≤32K档常规价格为输入0.2元、输出0.8元／百万tokens，已用于本项目的保守费用估算。

用户说明账户有1M免费额度。平台如何抵扣、额度余额及有效期未独立核验；这里记录的费用为抵扣前估算，不表示实际扣款。失败请求保留费用预留，不假定超时请求免费。

## 实际发现的问题与适配

首次结构化调用成功，但完整核对问答有一次超过30秒后回退本地。服务返回的usage显示成功请求中包含较多reasoning_tokens。查阅[Qwen思考模式说明](https://help.aliyun.com/zh/model-studio/deep-thinking/)后，增加可配置的 `enable_thinking=false`，以适合账单结构化和简短核对问答；不延长超时来掩盖问题。

修复前原始记录保存在results/api_validation_before_thinking_fix.json；修复后为results/api_validation.json。全部测试只使用明确构造账单或匿名汇总。

|验证项|修复前|关闭思考后|结果|
|---|---:|---:|---|
|净支出结构化计算|15.043秒|3.280秒|10000分支出减2000分退款，返回8000分|
|核对问题问答|31.915秒后超时回退|6.189秒|真实API返回当前核对问题与汇总|
|退款口径解释|24.788秒|6.195秒|按到账月说明退款冲减净支出|

上述三项复测全部通过，返回的usage合计2435 tokens，按常规未命中缓存单价估算0.000851元。该估算没有把免费额度写成收费单价0，也没有把未命中缓存的输入擅自按缓存价计费。

## 复现

配置本地.env中的地址、模型、密钥和当前平台单价后，启动本地网页服务，再执行：

```powershell
.\.venv\Scripts\python.exe scripts/validate_api.py --live
```

该命令会消耗少量tokens；不加--live不会发起请求。默认按UTF-8字节数加协议余量保守检查输入长度，将请求限制在32K计费档以内。费用限制只覆盖本项目发起的请求，不替代平台额度和账单。
